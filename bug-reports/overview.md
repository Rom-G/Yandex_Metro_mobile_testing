## Ключевые наблюдения

1. **50 % дефектов находятся в зоне рефакторинга.** 9 из 18 дефектов (BR-005…BR-013) связаны со сменой ориентации и лонг-тапом — областями, затронутыми рефакторингом. Это подтверждает приоритизацию регрессионного прогона.
2. **Критический дефект вне чек-листов.** BR-006 (краш при смене ориентации) выявлен в exploratory-сессии и является блокирующим для релиза.
3. **Кластер дефектов ориентации.** BR-005, BR-006, BR-007, BR-008, BR-009, BR-010, BR-011 имеют общий корень — обработка состояний карточек и масштаба при смене ориентации. Рекомендуется сгруппировать пакет для разработки и проверять единым регрессом после исправления.
4. **Дефект BR-014 блокирует проверку FT-034** — уведомление об ошибке не появляется, восстановление сигнала проверить невозможно.
5. **Разграничение сценариев энергосбережения.** Дефект BR-017 воспроизводится только при включённом режиме энергосбережения (RT-029); при низком заряде аккумулятора без энергосбережения (RT-028) поведение корректно.
